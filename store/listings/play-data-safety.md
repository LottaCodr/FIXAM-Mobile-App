# Google Play Data safety answers

Approximate answers for Play Console → App content → Data safety.

**Does your app collect or share user data?** Yes, collect. We do not sell data.

| Data type | Collected | Shared | Purpose | Optional |
| --- | --- | --- | --- | --- |
| Name | Yes | With assigned artisan | App functionality | No |
| Email | Yes | Flutterwave | App functionality, payments | Yes |
| Phone | Yes | SMS provider, artisan | App functionality | No |
| Address | Yes | Assigned artisan | App functionality | No |
| User IDs | Yes | No | App functionality | No |
| Payment info | Yes (token / last-4, not PAN) | Flutterwave | Payments | No |
| App interactions | Yes | No | Analytics / functionality | Yes |

**Security practices**
- Data encrypted in transit (HTTPS / TLS)
- Users can request deletion (in-app Delete account)
- Users can request deletion of account created in the app: **Yes**

**Advertising ID:** Not used.

**Independent security review:** No (unless you later complete one).
